# 工具箱：文件时间管理与自动输入设计

日期：2026-07-15

## 目标

在现有 Toolbox 中新增“文件时间管理”和“自动输入”两个本地工具。功能参考 `工具箱/文件时间管理` 与 `工具箱/自动输入` 中的旧脚本重新实现，不复用旧脚本进程和独立虚拟环境，不调用大模型，不持久化任务产物。

## 总体架构

- 前端新增两个独立页面：`/toolbox/file-time` 与 `/toolbox/auto-input`。
- 后端新增两个独立 API 模块，统一挂载在 `/toolbox` 下。
- 目录选择由后端调用 Windows 原生文件夹选择窗口完成，返回本机绝对路径；页面同时允许手动编辑路径。
- 文件处理与自动输入任务使用后端内存状态，不写入 SQLite。
- 长任务放入后台线程，接口立即返回任务 ID；前端轮询状态并展示进度。
- 不引入旧脚本依赖的 `pywin32` 和 `pynput`，改用 Python 标准库 `ctypes` 调用 Win32 API。

## 文件时间管理

### 支持的操作

1. **创建时间跟随修改时间**：递归扫描输入目录，把每个文件的 Windows 创建时间设置为当前修改时间。
2. **修改时间跟随创建时间**：递归扫描输入目录，把每个文件的最后修改时间设置为当前创建时间。
3. **从文件名恢复创建时间**：支持以下时间格式：
   - `YYYY-MM-DD-HH-mm-ss`
   - `YYYYMMDD_HHmmss`
   - `YYYYMMDD-HHmmss`
   - `YYYYMMDDHHmmss`
   识别成功的文件更新创建时间；识别失败的文件移动到输出目录，并保持相对目录结构。
4. **按创建日期移动文件**：把创建时间落在所选起止时间内的文件移动到输出目录，并保持相对目录结构。结束日期按当天 `23:59:59.999999` 计算。

逐文件手动设置创建时间不纳入新工具。

### 输入与输出目录

- 所有操作都要求输入目录存在且为目录。
- 只有“从文件名恢复创建时间”和“按创建日期移动文件”要求输出目录。
- 输出目录可不存在，执行时自动创建。
- 输入、输出目录不能相同。
- 输出目录位于输入目录内部时，扫描必须排除整个输出子树，避免再次处理已移动文件。
- 若目标文件已存在，不覆盖；该文件记为失败并返回明确原因。

### 执行流程

1. 用户选择操作和目录，日期移动模式额外选择起止日期。
2. 点击“扫描预览”，后端只读取文件信息，返回总文件数、预计更新时间数、预计移动数、跳过数和少量示例路径。
3. 用户确认后执行，前端显示进度、成功数、跳过数与失败数。
4. 完成后展示摘要和错误明细；原始文件列表及执行记录不持久化。

## 自动输入

### 输入配置

- 主要输入源为页面文本编辑区。
- 支持选择本地 `.txt` 文件，由浏览器读取 UTF-8 文本并填入编辑区，不上传文件。
- 可配置每字符间隔，范围 `0–2` 秒，默认 `0.05` 秒。
- 可配置开始前倒计时，范围 `1–30` 秒，默认 `5` 秒。
- 空文本不能启动。

### 执行机制

- 点击开始后，后端创建单个自动输入任务并立即返回任务 ID。
- 倒计时期间用户切换到目标窗口；倒计时结束后，后端使用 Win32 `SendInput` 的 Unicode 键盘事件逐字符输入。
- 后端实时记录 `countdown`、`running`、`completed`、`cancelled`、`failed` 状态和已输入字符数。
- 页面显示倒计时、百分比、已输入字符数和总字符数。
- 用户可在倒计时或输入阶段取消；任务在下一个字符边界停止。
- 同一时间只允许一个自动输入任务运行，防止多个任务争抢系统焦点。

### 边界行为

- 换行符转换为 Enter 键事件；其他字符使用 Unicode 输入事件。
- 自动输入只支持 Windows 桌面会话。系统不支持或后端运行在无桌面会话中时，返回明确错误。
- 页面关闭不会强制中断已开始的任务；重新打开页面可读取当前活动任务状态。

## 前端呈现

- Toolbox 首页新增 `FILE TIME` 与 `AUTO TYPE` 两张功能卡。
- 两个页面延续 Toolbox 的深色工业编辑台视觉，但使用各自的操作图形和状态色。
- 文件时间页采用“左侧参数控制台 + 右侧扫描/执行报告”布局。
- 自动输入页采用“左侧参数与启动控制 + 右侧大文本编辑区/进度层”布局。
- 所有执行按钮明确区分预览、确认和取消，避免误操作。

## API 边界

### 通用目录选择

- `POST /toolbox/system/select-directory`
  - 请求：可选 `title`、`initial_directory`
  - 响应：用户选择的绝对路径；取消时返回 `cancelled: true`

### 文件时间管理

- `POST /toolbox/file-time/preview`
- `POST /toolbox/file-time/jobs`
- `GET /toolbox/file-time/jobs/{job_id}`

### 自动输入

- `POST /toolbox/auto-input/jobs`
- `GET /toolbox/auto-input/jobs/active`
- `GET /toolbox/auto-input/jobs/{job_id}`
- `POST /toolbox/auto-input/jobs/{job_id}/cancel`

## 错误与安全边界

- 后端验证所有路径、操作类型、日期范围和数值范围。
- 文件系统错误按文件记录，单个文件失败不终止整个批次。
- 目录选择窗口串行执行，防止多个原生窗口同时弹出。
- 本功能面向本机开发环境，不增加账户权限或鉴权逻辑。

## 测试与验收

- 单元测试覆盖四种文件名时间格式、非法日期、目录排除、目标冲突和日期边界。
- 使用临时目录完成文件时间预览与执行集成测试，不触碰用户真实文件。
- 自动输入通过注入假的键盘发送器测试倒计时、逐字符进度、取消和并发限制，不在自动化测试中真实发送按键。
- 前端单元测试覆盖请求参数、状态映射和操作模式约束。
- 生产构建和完整后端测试通过后，使用 Chrome 插件验收两个页面的布局与交互；不在浏览器验收中执行真实批量文件修改或向其他窗口自动输入。
