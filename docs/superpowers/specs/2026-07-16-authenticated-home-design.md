# 登录后主页设计规格

## 目标

在公开项目展示页与 Studio 之间增加一个登录后主页，作为用户每天进入 AgentBI 的个人头版。页面以时间、问候、格言和氛围展示为主体，同时提供四个主模块入口与最近三个 Studio 会话的继续入口。

主页不是统计仪表盘，不承担业务配置和复杂状态监控。它应在没有会话数据或部分接口失败时仍可完整承担模块导航职责。

## 路由与登录流程

- 保留 `/` 作为未登录用户可访问的公开展示页。
- 保留 `/login` 作为登录页。
- 新增受保护路由 `/home`，页面名称使用 `authenticated-home`。
- 登录成功后从 `/login` 跳转到 `/home`；若登录前携带了明确的受保护目标 `redirect`，仍优先回到该目标。
- 已登录用户直接访问 `/` 或 `/login` 时跳转到 `/home`。
- Studio、Live、Test 与 Toolbox 的品牌标识提供返回 `/home` 的入口，但主页不作为 Studio / Live / Test 的第四种工作模式。
- 最近会话通过 `/chat?conversation=<id>` 进入；现有 ChatView 已支持该查询参数并会选中目标会话。

## 页面信息架构

### 1. 顶部状态线

顶部保留极简状态信息：AgentBI 字标、当前日期、用户头像或姓名缩写，以及退出入口。字标点击停留在主页。

### 2. 时间与问候主体

- 使用浏览器本地时间，每分钟更新，不请求后端时间服务。
- 时间以超大字号显示小时与分钟，秒数仅作为弱化的辅助信息或动态刻度。
- 日期使用本地化的星期、月份与日期格式。
- 根据本地小时显示早上好、下午好、晚上好或夜深了。
- 用户名优先使用认证状态中缓存的数据库 `username`，缺失时回退到邮箱前缀。

### 3. 轮换格言

格言存放于独立文件 `Agent-vue/src/content/home-quotes.json`，不写入组件、不进入 SQLite。

每条数据结构固定为：

```json
{
  "text": "台词或格言正文",
  "source": "作品名或来源，可为空",
  "speaker": "角色或作者，可为空"
}
```

- 页面加载时随机选择起始项，避免每次都从第一条开始。
- 默认每 10 秒轮换一次。
- 使用淡出、轻微擦除和输入光标组合动效，不逐字符执行冗长打字动画。
- 用户标签页不可见时暂停轮换，重新可见后继续。
- 开启 `prefers-reduced-motion` 时取消擦除与位移动画，仅使用瞬时或短淡入切换。
- 格言文件为空或读取失败时隐藏整个格言区域，不显示错误占位。

### 4. 主功能入口

主入口采用非对称编辑式构图，避免四张等宽同构卡片：

- Studio：最大入口，承担视觉主卡。说明其为多模型、工具与子代理工作台，跳转 `/chat`。
- Live：强调实时语音、角色与通话，跳转 `/live`。
- Test：强调知识测试与趣味测试，跳转 `/test`。
- Toolbox：强调无对话的本地工具集合，跳转 `/toolbox`。

每个入口包含英文序号、模块名、一句用途说明和方向箭头。悬停时通过文字位移、边界展开与背景纹理变化反馈，不使用统一抬升阴影卡片效果。

### 5. 最近三个 Studio 会话

- 先复用现有助手列表接口，再为每个助手并行调用 `listConversations(userId, assistantId)`。
- 将各助手结果在前端按 `last_message_at` 合并排序，只保留最近三项；不新增后端聚合接口。
- 使用已加载的助手列表将 `assistant_id` 映射为助手名称；映射失败时省略助手名。
- 每项展示会话标题、助手名称和相对更新时间。
- 点击会话跳转 `/chat?conversation=<id>`。
- 无会话时展示一句轻量引导和“开始第一个会话”入口。
- 单个助手的会话接口失败时保留其他助手的结果；助手列表整体失败时回退到默认助手会话。
- 所有会话请求均失败时隐藏最近会话列表，仅保留“进入 Studio”，不弹阻塞式错误。

### 6. 次级快捷入口

页面底部以文字导航形式提供：

- 模型工作室 `/settings/models`
- 助手管理 `/assistants`
- 附件库 `/attachments`
- 能力配置 `/settings/capabilities`

这些入口不与四个主功能争夺视觉层级。

## 视觉方向

整体方向为“时间编辑部 / Daily Briefing”：像一张每天自动更新的个人头版，而不是 SaaS 仪表盘。

- 主色使用暖灰黑、纸张白与现有荧光黄绿色强调色。
- 使用大字号时间、细线网格、编号、边注和不对称留白建立编辑感。
- 背景可包含极低对比度的网格、时间刻度和颗粒纹理，不使用紫色渐变、玻璃拟态卡片墙或通用 Bento Dashboard。
- 页面入场动画只编排一次：状态线、时间、问候、格言、功能入口、最近会话依次出现。
- 所有持续动画保持低频、低幅度；页面使用一段时间后不能产生明显视觉噪声。
- 宽屏采用错位网格，窄屏按时间主体、功能入口、最近会话、次级入口顺序自然堆叠。

## 数据流与组件边界

新增页面 `AuthenticatedHomeView.vue` 负责页面编排，不直接承载所有逻辑。辅助单元划分为：

- `home-time.ts`：问候语、日期、时间和相对时间格式化的纯函数。
- `home-quotes.ts`：加载格言、随机起始与安全轮换索引的纯逻辑。
- `HomeModuleEntry.vue`：单个主功能入口的语义与交互组件。
- `HomeRecentConversations.vue`：按助手并行加载会话、合并排序、助手名称映射、空状态与降级显示。
- `home-quotes.json`：唯一的格言内容来源。

认证信息直接读取现有 `useAuthStore`。最近会话与助手数据调用现有 API，不新增后端路由、数据库字段或缓存层。

## 异常与边界状态

- 用户资料仅有邮箱时，问候使用邮箱前缀。
- 会话标题为空时显示“未命名会话”。
- 时间字段无效时省略相对时间，不显示 `Invalid Date`。
- 助手已删除或无法映射时只显示会话标题。
- 接口加载期间使用三条短线式骨架，不显示全屏 Loading。
- 最近会话加载失败不产生全局错误提示，也不阻止任何导航。
- 页面卸载时清理时钟和格言计时器，避免重复定时任务。

## 可访问性

- 主入口使用真实链接或可访问的路由链接，不使用仅绑定点击事件的无语义容器。
- 时间更新区域不使用持续 `aria-live`，避免读屏器每分钟打断用户。
- 格言轮换不主动向读屏器播报。
- 所有文字与背景满足可读对比度，键盘焦点具有清晰轮廓。
- 动效遵循 `prefers-reduced-motion`。

## 测试与验收

### 单元测试

- 时段问候边界：清晨、上午、下午、晚上和深夜。
- 日期与相对时间格式化不会产生无效文本。
- 格言随机起始索引和循环索引保持在合法范围。
- Deep link 正确生成 `/chat?conversation=<id>`。
- 会话跨助手合并排序、部分请求失败与助手缺失回退行为。

### 页面验收

- 未登录访问 `/home` 会跳转登录页并携带 redirect。
- 登录成功默认进入 `/home`。
- 已登录访问 `/` 与 `/login` 进入 `/home`。
- 四个主入口与四个次级入口均跳转正确。
- 最近三个会话可直接进入对应 Studio 会话。
- 无会话、会话接口失败、格言为空时页面仍完整可用。
- 桌面端和移动端布局无横向溢出。
- Chrome 中验证视觉、键盘焦点、格言轮换和 reduced-motion 行为。

## 非目标

- 不加入天气、地理位置、日历、任务管理或在线状态监控。
- 不加入可视化主页编辑器或卡片拖拽排序。
- 不允许用户在页面内编辑格言。
- 不新增主页专用后端接口或数据库表。
- 不把主页加入 Studio / Live / Test 模式切换器。
